# ☕ Coffee Sales Analysis & Interactive Excel Dashboard

## 📊 Project Overview

This project presents an interactive Coffee Sales Analysis Dashboard developed using Microsoft Excel.

The purpose of this project is to transform raw coffee sales data into meaningful business insights by analyzing sales trends, customer performance, product preferences, roast types, loyalty-card usage, and order patterns over time.

The dashboard combines data analysis, Pivot Tables, Pivot Charts, Timeline filtering, and interactive slicers to create a user-friendly business reporting solution.

---

## 🎯 Business Objective

The objective of this project is to analyze coffee sales data and answer important business questions such as:

- How do sales change over time?
- Which customers generate the highest sales?
- Which roast types contribute to sales?
- How does loyalty-card usage relate to customer purchases?
- Which product sizes are most commonly purchased?
- How does sales performance vary across different periods?
- Which customers contribute significantly to overall revenue?

The analysis is designed to help businesses understand customer behavior and sales performance and support data-driven decision-making.

## 📈 Dashboard Features

### 1. Sales Trend Analysis

The dashboard visualizes total sales over time, allowing users to identify changes and patterns in sales performance across multiple years and months.

### 2. Top 5 Customer Analysis

The dashboard identifies the top customers based on their sales contribution, helping highlight high-value customers.

### 3. Roast Type Analysis

Users can filter the dashboard by different coffee roast types, including:

- Dark
- Light
- Medium

This allows sales performance to be explored across different product categories.

### 4. Loyalty Card Analysis

The dashboard includes an interactive loyalty-card filter that allows users to compare sales behavior between customers with and without loyalty cards.

### 5. Product Size Analysis

Users can filter the analysis based on different product sizes, including:

- 0.2kg
- 0.5kg
- 1.0kg
- 2.5kg

### 6. Time-Based Analysis

An interactive Order Date Timeline allows users to analyze sales performance across different months and years.
